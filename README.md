# CT240T-Lab3-HotelBooking

Bài tập cá nhân: Unit Test cho `BookingService` bằng JUnit 5 + Mockito, đo độ bao phủ bằng Jacoco.

## Chạy
```
mvn clean test
```
Báo cáo Jacoco: `target/site/jacoco/index.html` (chụp màn hình để nộp/đính kèm PR).

## Git
```
git init
git checkout -b feature/unit-tests-booking-service
git add .
git commit -m "test(booking): bo sung unit test JUnit 5 va Mockito cho BookingService"
git push origin feature/unit-tests-booking-service
```
